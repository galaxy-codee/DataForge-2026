Submission: **Where Memory Breaks — Linear Attention vs. Softmax Attention** · DataForge 2026, Pathway Track.

This file is the authoritative record of every reused component, its origin, and its license. It covers code, data, model weights, graphics, fonts, and any third-party material.

## 1. Third-party code and libraries

| Component | Version | Source | License | How it is used |
|---|---|---|---|---|
| KaTeX (CSS + JS) | 0.16.9 | `https://cdnjs.cloudflare.com/ajax/libs/KaTeX/0.16.9/` (cdnjs) | MIT | Typesets the mathematical notation. Loaded from CDN at runtime; not vendored into this repository. No other third-party JavaScript, CSS, or build tooling is used. There is no package manager, no bundler, no framework, and no `node_modules`. The artifact is a single self-contained HTML file.

## 4. Data and model weights

| Item | Status |
|---|---|
| Datasets | **None used.** All keys, values, and facts are generated at runtime by a seeded pseudo-random number generator (`mulberry32`, a small public-domain-style PRNG re-implemented from its widely published form) inside the artifact. No external dataset is downloaded, bundled, or referenced. |
| Model weights | **None used.** No pretrained checkpoint, no BDH or BDH-CQ weights, no API calls to any hosted model. Every number displayed is computed in the reader's browser from synthetic vectors. |
| Network calls at runtime | Only the KaTeX CDN request above. No analytics, no telemetry, no tracking, no fonts fetched, no data sent anywhere. |
