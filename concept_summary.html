Linear Attention: buying a memory that stops growing, and paying for it in recall

One-page concept summary · DataForge 2026, Pathway Track · companion to the interactive explainer Where Memory Breaks

For a data scientist meeting linear attention for the first time. Prerequisites: dot products, matrix–vector multiplication.

The design pressure

A Transformer scores each query against every earlier token, so it must retain every key and value it has seen. That KV cache grows with context length and bottlenecks inference memory [1]. Linear attention removes the all-pairs comparison by reordering the computation: instead of comparing token pairs, it carries one fixed-size state that each token updates additively, S ← S + φ(kt) ⊗ vt, and answers a query by reading r(q) = φ(q)⊤S. Per-token cost becomes constant in sequence length, and the state has the same shape after ten tokens as after ten million.

What the change costs

The state is a superposition: every association is summed into the same matrix, so nothing is stored separately. Probing it with the key that wrote a fact returns that fact plus a weighted sum of every other stored value:

r(ki) = (ki⊤ki)vi  +  Σj≠i (ki⊤kj)vj
The central claim our explainer teaches: a fixed-shape state can absorb an unbounded stream of key–value facts, but because all writes are superposed, retrieval degrades as facts accumulate or as keys grow more similar — and enlarging the state postpones that failure rather than removing it.

Arora et al. identify this as a direct state-size/recall trade-off and show that fixed-state alternatives such as H3, Mamba and RWKV "struggle at recall"; their BASED architecture makes state size a dial traversing the recall–memory Pareto frontier, beating comparable sub-quadratic models on recall-intensive tasks by 10.36 accuracy points [1]. Pandey & Singh sharpen the cause: the state grows as O(T) in Frobenius norm, "causing progressive interference between stored associations" [2]. Zhong et al. formalise the same separation as a retrieval signal-to-noise ratio under an associative-memory reading of attention [3].

Where BDH and BDH-CQ actually fit

Their relevance is real but unequal. BDH (Dragon Hatchling) reformulates attention as synaptic memory: reasoning and memory share one computational fabric, associations are written by Hebbian updates between co-active neurons, and activity is sparse and non-negative — roughly 5% of neurons active in reported runs. Its GPU-oriented formulation, BDH-GPU, is built from ReLU-low-rank transformations with linear attention, which is the direct link to this concept; it is explicitly not a state-space model in the Mamba sense. BDH-CQ is the closer case: its contextual memory is published as a general learned update St ← Uθ(St−1, Dt), and its report relates that memory to attention, fast-weight memory and linear-attention views of contextual association through an additive special case where state accumulates additively per demonstration. That special case — and only that — is what our explainer reimplements, as a labelled synthetic toy. We do not run BDH-CQ weights, and Uθ is not assumed additive.

The most important open question

Not whether gating or regularisation helps — both demonstrably do — but whether any fixed-size state can hold what a long-context task requires without growing the state or smuggling exact storage back in. Both leading fixes concede the capacity boundary rather than dissolve it: VLA's accuracy holds while stored pairs stay below the per-head dimension and drops to 62% at that boundary [2], and BASED's answer is explicitly a hybrid — linear attention plus sliding-window attention, state size as a knob [1]. Independent reproduction is the missing evidence throughout: the 2026 variational results and the BDH/BDH-CQ results are, as of writing, reported by their own authors.
