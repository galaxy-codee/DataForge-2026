01 · WRITE ONE FACT

Make an outer-product tile

k_j v_jᵀ

A key determines where the fact writes; a one-hot value determines which answer it supports.

02 · ACCUMULATE

Reuse the same state

S = Σ k_jv_jᵀ

The state shape stays fixed while the number of stored facts, N, grows.

03 · READ

Probe it with a query

r(q) = qᵀS

The output has one score per possible value. The largest score is the retrieved answer.

The failure mechanism

r(kᵢ) = (kᵢᵀkᵢ)vᵢ + Σᵢ≠ⱼ(kᵢᵀkⱼ)vⱼ
desired self-signalinterference from other keysfinal value scores

More facts or more similar keys increase the cross-talk term. A larger state can make unrelated keys more distinct, but it does not change the fact that all writes are superposed in one fixed-size state.

Plain English

Every fact gets stirred into the same small pot. Asking for one fact back mostly gives you that fact — plus a faint aftertaste of everything else that's been stirred in. More facts, or more similar facts, means a stronger aftertaste.

What the state actually looks like

Each row is one dimension of the fixed-size state; each column is a possible value. A clean memory shows a few sharp, separated cells. Zhong et al. (2025) formalize this separation as a retrieval signal-to-noise ratio — watch the picture blur as N grows past capacity.

Why anyone accepts this tradeoff at all

Softmax attention doesn't collapse — but it isn't free. To answer perfectly, it has to keep every key and value it has ever seen (its KV cache). Linear attention's state never grows, no matter how long the sequence gets. Module 8 of 11 · BDH-CQ connection

You just watched linear attention collide with itself. BDH-CQ hits the same wall — but describes it in its own vocabulary.

The connection: recurrent contextual memory, not an identity.

BDH-CQ's contextual memory update is published as a general, learned function S_t ← U_θ(S_{t-1}, D_t) — the state evolves once per demonstration, not once per token. The paper connects this to attention, fast-weight memory, and linear-attention views of contextual association through an additive special case, structurally identical to the outer-product write you just watched collide. Toggle the write granularity below to see what that special case costs a single key's resolution once several facts share one write.

BDH's own vocabulary for the Hebbian write you saw as k⊗v above: a small, sparse set of neurons fire together, and the synapse between them strengthens. That strengthened synapse is the write into memory.

This is an open problem, not a solved one. The interference you just caused by shrinking the demonstration group size is the same failure mode active research is racing to fix. Hatamizadeh, Choi & Kautz's Gated DeltaNet-2 (arXiv:2605.22791, May 2026) separates the "erase" and "write" decision into independent channel-wise gates so new writes can edit old associations instead of blindly summing over them. Pandey & Singh's Variational Linear Attention (arXiv:2605.11196, May 2026) attacks it from the other side — bounding the state's growth directly via a regularized update. Neither is BDH-CQ's own fix; they're evidence that the exact tradeoff this demo makes visible is still being actively contested, this year.
Plain English

BDH calls the fixed notebook a "synapse" and calls writing to it "two neurons firing together." It's the same trade-off you've been testing all along: cram a growing pile of facts into a shrinking, fixed amount of space, and some of them will start to blur together.

Shrinking the write granularity made things worse. It's tempting to think the fix is always "add more room" — it isn't.

The misconception this breaks

"Just make the state bigger" only pushes the collision point back — it doesn't remove interference as a structural property of superposing facts into a fixed-size vector. Try the Rescue preset above, then keep raising N: it fails again, later.

Limitation: capacity scales roughly with state size d, not with how important a fact is. Two facts with near-parallel key vectors will collide even at small N — the model has no way to know which memories are "worth" protecting.

Reference explanation: In this toy, linear attention compresses every key–value pair into one fixed-size matrix through additive updates. Standard attention keeps individual key–value pairs, so a longer sequence grows its memory use but lets a query compare against separate stored keys. Once many associations are superposed in a finite state, they interfere and the compact representation can return the wrong value. BDH-CQ shares the broader idea of a recurrent contextual state, but its published update is a learned function over demonstrations; this lesson’s additive toy is only a related special case, not an implementation of BDH-CQ.

Everything above is grounded in published work, not intuition. Here's where each claim actually comes from.

Primary sources

  • Arora et al., "Zoology: Measuring and Improving Recall in Efficient Language Models" (arXiv:2312.04927, ICLR 2024) — introduces multi-query associative recall (MQAR), the exact task this demo runs, and proves attention solves it with accuracy independent of model dimension while fixed-state alternatives need dimension that grows with sequence length.
  • Arora et al., "Simple linear attention language models balance the recall-throughput tradeoff" (BASED, arXiv:2402.18668, ICML 2024) — plots accuracy vs. recurrent state size on MQAR as its central result. This demo's main chart reproduces that same relationship on a small synthetic version of the same task.
  • Zhong, Xu, Ao & Shi, "Understanding Transformer from the Perspective of Associative Memory" (arXiv:2505.19488, 2025) — formalizes memory capacity via a retrieval signal-to-noise ratio (SNR) and uses a kernel view to explain why softmax attention resists the interference linear attention suffers from.
  • Pandey & Singh, "Variational Linear Attention: Stable Associative Memory for Long-Context Transformers" (arXiv:2605.11196, May 2026) — proves the standard linear-attention state grows unboundedly in Frobenius norm with sequence length, which is the precise mechanism behind the collapse shown above, and proposes a regularized update that keeps it bounded.
  • Yang, Kautz & Hatamizadeh, "Gated Delta Networks: Improving Mamba2 with Delta Rule" (arXiv:2412.06464, ICLR 2025) — a linear-attention variant now integrated into Qwen3-Next, a deployed production model, as evidence this tradeoff is a live engineering concern, not only a benchmark result.
